# Mapa de Documentos Capital Hub

Fuente obligatoria general: `docs/`.

Documentos canónicos principales:

- `docs/Manual_Proyecto_Capital_Hub.md` — misión, visión, propuesta de valor, fundamentos y posicionamiento.
- `docs/Brandkit_Capital_Hub.html` — identidad visual y diseño. Es ley para diseño, UI, landings, branding y creatividad.
- `docs/avatar-andres.md` — avatar canónico para contenido, copy, ads, emails, llamadas y oferta.
- `docs/brand-playbook.md` — marca personal de Adrián, narrativa, tono y temas públicos.
- `docs/sops/` — operación documentada por áreas.
- `docs/sops/producto/` — reglas de producto, mobile-first, deploy, colaboración y arquitectura OS/App.
- `docs/sops/marketing/` — funnel MIFGE, KPIs, tracking, checkout, emails y lead magnets.

Si una tarea contradice estos documentos, detenerse y preguntar antes de actuar.
